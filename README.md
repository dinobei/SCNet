# SCNet

## 개요
- protobuf 기반 메시지 송수신
- 네트워크 송수신 기능이 필요한 새로운 시스템을 구현시 항상 같은 방법으로 구현하는 부분을 사용하기 쉽게 라이브러리화 해서 개발 효율성 향상을 위함
- 설계된 구조를 다른 개발자와 공유하고 필요한 기능을 추가하거나 로직 자체의 성능 향상을 지속적으로 이룰 수 있음

## 사용방법
- 서버/클라이언트 공통
	- 필요한 프로토콜 설계
	- protobuf 메시지(*.proto 파일)를 정의한 뒤, protoc 컴파일러로 컴파일해서 *.pb.h, *.pb.cc 파일 획득
- 서버
	- 클라이언트 송수신 메시지를 처리하는 커스텀 로직 구현
- 클라이언트
	- 요청 및 응답에 대한 UI 로직을 구현
